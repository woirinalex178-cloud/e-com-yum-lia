## Sécurité

Le dépôt est actuellement public. Ne jamais y ajouter : identifiants Shopify, clés API, exports de commandes ou de clients, documents fournisseurs non publics, marges, factures ou coordonnées personnelles.  
Si l'on veut y centraliser des données internes détaillées, le dépôt devra d'abord passer en privé.

La boutique elle-même reste la source de vérité pour les réglages, produits, commandes et paiements. Ce dépôt est le journal de pilotage et de travail.
