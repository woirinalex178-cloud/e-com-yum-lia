# Règles du dépôt

## À documenter ici

- décisions qui changent le site ou la stratégie ;
- éléments terminés et contrôles effectués ;
- tâches restantes et leur priorité ;
- modifications de contenu, de navigation ou de tunnel ;
- problèmes rencontrés et leur résolution.

## À ne jamais documenter ici tant que le dépôt est public

- mots de passe, clés API, jetons d’accès ou fichiers de configuration secrets ;
- exports Shopify contenant des clients, commandes, adresses ou e-mails ;
- coordonnées de fournisseurs, coûts d’achat, marges ou factures ;
- captures d’écran laissant apparaître des données personnelles.

## Mise à jour simple

Après une session de travail :
1. mettre à jour `AVANCEMENT.md` ;
2. cocher ou ajouter les tâches dans `BACKLOG.md` ;
3. consigner toute décision durable dans `DECISIONS.md` ;
4. ajouter une ligne courte dans `CHANGELOG.md`.
